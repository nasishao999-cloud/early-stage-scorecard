# 早期项目 AI 初筛

这是早期项目评估网页 v13-v5，含 18 项人工复核。网页、样式、评分逻辑和报告导出代码都内嵌在 `index.html` 中。

[打开在线版](https://early-stage-scorecard.nasishao999.chatgpt.site)

## 使用方法

1. 在 GitHub 选择 **Code → Download ZIP**，解压后用 Chrome 打开 `index.html`。也可以在本地克隆仓库后直接打开，无需构建。
2. 填写项目与交易背景，生成并复制提示词。将提示词和可分享的项目资料交给所选 AI 工具，再把完整回复粘贴到「AI 分析导入」。
3. 在「分项评分」逐项用 0–4 级滑杆复核，点击该项「确认」后重算。也可只补判断依据，在「复核历史」查看记录。
4. 按需补充决策证据，下载 Word 或 TXT 报告，或保存含人工复核记录的 JSON 草稿。

网页在浏览器中处理导入、评分和导出。草稿保存为本地 JSON 文件。
