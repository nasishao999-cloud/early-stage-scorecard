# 早期项目 AI 初筛

把可共享的 BP 交给 AI 工具，再把回复导入本网页，即可查看 18 项评分、逐项人工复核并导出报告。

**[打开在线版 v13-v5](https://early-stage-scorecard.nasishao999.chatgpt.site/)**

建议用电脑 Chrome 打开。在线版无需登录或下载。

## 使用说明

**可以从空白表单直接开始。** AI 根据 BP 提取项目信息，导入回复后，网页会自动回填项目名称、行业、融资轮次、项目阶段和核心产品等字段。

1. **生成分析。** 点击「生成并复制 AI 提示词」，把提示词和可共享的 BP 或项目材料一起交给公司允许使用的 AI 工具。
2. **导入回复。** 复制 AI 的**整条回复**，粘贴到网页的「AI 分析导入」，点击「校验并导入」。导入后先核对自动回填的项目信息，再看默认展开的待核提示。如果格式校验失败，请让 AI 按「首行结论＋一个 JSON 代码块」重发完整回复。
3. **人工复核。** 在「分项评分」用 **0–4 级滑杆**调整需要复核的评分，也可以只补依据。**每项点「确认」后才会重算总分。** 如需补充主体、刚需或付费证据，在「初筛决策证据」填写后点「应用复核资料并重算」。
4. **导出或续做。** 点「下载 Word 报告」，可导出复核后的总分和改分记录。需要下次继续时，点「保存评估草稿」下载 JSON，再用「打开评估草稿」恢复。

AI 评分用于初筛。涉及项目去留的判断，请结合原始材料和人工复核结果。

## 本地使用

如需本地运行，在 GitHub 选择 **Code → Download ZIP**，解压后用 Chrome 打开 `index.html`。网页、样式、评分与报告导出代码均内嵌，无需构建。网页在浏览器中处理导入、评分和导出，草稿可保存为本地 JSON 文件。
